01

Button

3px radius, 36/44px heights. Primary is --text-1 on --surface-3 with a 1px lift, and is never signal-filled: signal means dispute, not "click me". Destructive is the one control signal touches, and even there it is an edge and a word, never a fill.

States: all 8. Empty is N/A — a button with no label is a defect, not a state.

02

IconButton

32px visual box, 44px hit area via a pseudo-element so the box does not grow (WCAG 2.2 SC 2.5.8). Tooltip after 400ms. Every instance carries an accessible name; an icon is not a label.

States: default, hover, focus, active, pressed, disabled, loading. Empty and error are N/A.

03

Input

Label above in col, error below in micro signal. The value itself is set in Sligoil with tabular figures, because an input on this product usually holds a machine fact.

States: all 8.

04

Select

Native element, our skin. The full ARIA combobox listbox lands in FE-7 where it has real data to hold — shipping a fake one now would be a component without a job.

States: default, hover, focus, disabled, error, empty. Loading and active are N/A on a native control.

05

Checkbox

16px, 2px stroke, --m-instant. Indeterminate is a real state here: a class is partly selected when some of its records are.

States: default, checked, indeterminate, hover, focus, disabled, error. Loading and empty are N/A.

06

Radio

The one legitimate circle in a system where radius is 0 or 3px: a radio that is not round stops reading as a radio.

States: default, checked, focus, disabled. Loading, error and empty are N/A.

07

Toggle

Binary settings only. Never for filters — a filter needs to read as "on for this value", which a switch cannot say. Square-ended, because 999px never.

States: off, on, focus, disabled. Loading, error and empty are N/A.

08

Tabs

2px underline, slides at --m-base, roving tabindex. The underline is --text-1, not signal: a selected tab is not a dispute.

States: default, selected, hover, focus, disabled, loading, empty. Error is N/A — an errored panel is the panel's state, not the tab's.

09

Tooltip

--surface-3, micro, 6px offset, 400ms delay, never on touch. It supplements an accessible name; it never carries the only copy of a fact.

States: hidden, shown, focus-within. Loading, error, disabled and empty are N/A.

10

Toast

Bottom-left, stacks to 3, auto-dismiss 6s, pause on hover, role="status". Shown inline here so the gallery can be screenshot-diffed.

States: default, loading, error, settled. Hover/focus/disabled are N/A on a status region.

11

Modal

Focus trap, Esc, scrim --p-scrim, returns focus on close. Shown inline rather than over the page so both themes are diffable.

States: default, loading, error. Hover/disabled/empty belong to its contents.

12

Drawer

Right, 480px, same trap rules as Modal. Slides at --m-slow; under reduced motion it cross-fades instead, which is a designed alternative, not a disabled one.

States: closed, open, loading, empty. Shown here as a static panel.

13

Menu

Roving tabindex, type-ahead, and the ⌘K palette shares its renderer — one list, two entry points.

States: default, active, disabled, empty, loading. Error is N/A.

14

DataTable

Sticky head, hairline rows, tabular numerals (LAW), virtualised beyond 200 rows. Hover is background only — never lift, never move: a row that jumps under the cursor makes a reader lose the line they were checking. A disputed row gets a plane of signal with a 2px edge on the datum side, never a dot.

States: default, hover, selected, disputed, settled, loading, empty, error. All 8 present.

Defect C-2 — this table is not the queue. Blueprint §13.2 specified a queue ranked by a right-aligned Conf. column. FR-7.5 (P0) forbids exactly that: queue rows render as a sentence, never a bare confidence percentage, and no UI surface may show a raw confidence score as the primary signal. The PRD wins over the blueprint. DataTable keeps this shape for the record detail, the benchmark and the coverage report; the queue is component 21. Logged in FE-SYSTEM-REVIEW.md §2.

15

Confidence

Five segments, achromatic on purpose. A green/amber/red bar would be the product telling you how to feel about a number it has just asked you to check yourself.

States: full range, empty (uncalibrated), disabled. Hover/focus/error are N/A — it is a readout, not a control.

16

ProvenanceTag

Institution + identifier + retrieved date, in micro, hanging in the margin. §7.4 makes provenance a LAW; this is the component that discharges it. Its empty state is not blank — it accuses.

States: default, empty (missing provenance). Interactive states are N/A.

17

DiffPair

The signature data component: the catalog value in Redaction 50 above the evidence value in Redaction 0. The reader watches an unverified claim resolve into a grounded one, in type, without a legend. With the Redaction files absent this reads as one face struck through — the axis is the part you cannot judge yet.

States: disputed, settled, empty (no evidence found). Interactive states are N/A.

18

DocumentView + SpanHighlight

Real DOM or a PDF.js text layer — never an image-only render, because spans must be selectable (L-6). Paper in both themes (L-2), with the 2px signal reveal on the datum side (L-3). Compare the two panes: everything else inverts and this does not.

States: default, loading, empty, error. Hover/focus belong to the spans.

19

SectionOpener

Number in poché, hairline above, opener in Redaction 20 — derived and calibrated, not raw source. One lead per section, and never a second.

States: default only. This component has no interaction to have states about.

20

ThemeToggle

Three-state: system / light / dark. A radiogroup, not a switch — a switch with three positions is a lie about its own affordance. Arrow keys traverse. The live one is in the page header; these are static.

States: each of three selected, hover, focus, disabled. Loading/error/empty are N/A.

21

QueueRow

Added after the FE system review, to discharge FR-7.5. The row is prose because the requirement is prose. It carries FR-8.4's four blast-radius factors separately — "each factor must be independently inspectable in the UI", because a reviewer shown one opaque score has been given a number, not a reason — and FR-8.5's computed cluster size. Confidence is not absent from the product; it is absent from the queue, and lives on the record detail where the evidence is in front of the reviewer.

States: disputed, declined (abstention), settled, awaiting second adjudicator (FR-8.9), hover, current, loading, empty. Discharges FR-7.5 · FR-8.4 · FR-8.5 · FR-8.9.

Documentation

Running it, reading what it produces, and checking its work without taking our word for any of it.

Install and run

bash scripts/setup.sh          # virtualenv and the seven packages
bash scripts/ci.sh             # everything that must be true, in one command
bash scripts/ci.sh --fast      # skip the steps needing fetched reference data

The same script runs locally and in continuous integration, deliberately. A pipeline that exists only as a YAML file nobody can execute is a second, invisible definition of "correct" that drifts from the first one.

The reviewer console

errata-audit serve             # the queue, the evidence pane, the claim history

It runs on your machine and talks to nothing off-origin. The page image is regenerated from the exact bytes the claim was made against — named by content hash — rather than from whatever is at the supplier's URL today.

Checking our work

An Evidence Bundle is a self-contained file: the claim, the evidence spans, the page images, the projection that placed the boxes, and a digest over all of it. It verifies without this software, and the verifier runs in a browser as well as in Python. 

errata-r3 reproduce            # re-derive the published numbers from source
errata-r3 gold verify          # the gold set re-derives from the documents
errata-r3 split verify         # the frozen test split is untouched

These are the same commands the build runs. If a published number and the code ever disagree, one of these fails — which is the point of publishing a receipt rather than a figure.

Reading a decline

Every record that was not audited carries exactly one reason. The ones worth knowing before you see them:

  • no_source_document — nothing to ground against. Feeds the document-recovery queue.
  • layout_unreadable — the layout defeated us: fold-out, rotated table, table split across pages.
  • ocr_text_not_evidence — the document is a scan carrying an OCR layer. The text is legible; that is the problem.
  • value_outside_known_grammar — the value parser refused. Surfaced, never guessed.
  • equal_rank_source_conflict — two sources of identical rank disagree; policy declines to arbitrate.
  • calibration_out_of_distribution — too few labels in this class for the confidence estimate to be honest.

A decline is a result. There are no silent skips anywhere in the pipeline, because a system that quietly skips what it cannot handle is indistinguishable from one that handled it.

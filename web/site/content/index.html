Errata lives in the 49-point gap. It ingests a catalog and the source documents behind it, independently re-derives every attribute, grounds each value to a word-level span, calibrates its own confidence, and emits a ranked list of records where the catalog and the evidence disagree — with the evidence attached.

02

It grades data. It does not create data.

The output is a redline addressed to a human, and it carries the case against itself.

Claims, not values

Nothing stores “the value of attribute X”. It stores immutable assertions about that value, each with its evidence, its extractor fingerprint and its calibrated confidence.

Abstentions are a type

Not a null, not an empty string. A type the downstream code cannot mistake for a value — because on this corpus, declining is the majority behaviour.

Redlines, not writes

No code path reaches a customer’s PIM. Accepting a correction writes a claim to Errata’s own append-only ledger saying a human accepted it (ADR-001).

Two signatures

Safety-class attributes need a second named adjudicator. Single-signature acceptance is impossible by construction — the schema refuses it (FR-8.9).

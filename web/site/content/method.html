Method

Errata grades data. It does not create data. Every number it shows you came off a page in a document you can open, at coordinates you can check, and where it could not find one it says so instead of estimating.

The six steps

  1. Ingest. The catalog row and the source document are registered by content hash, never by filename. A supplier who reposts a revised datasheet at the same URL gets a new revision, not a silent overwrite.
  2. The text layer. One canonical extraction per document revision, version-stamped and cached by content hash. Word order is the extractor's own reading order, never re-sorted — a claim stores a character offset into this text, and an ordering that "improves" between releases invalidates every stored offset while every test still passes.
  3. Class resolution. The row is matched to an ETIM class in three named stages, and each stage is shown. A class chosen by a step nobody can see is a class nobody can dispute.
  4. Blind re-derivation. The extractor is not shown the catalog's value. This is enforced by the function signature and pinned by a test: a channel through which the answer could arrive would make every agreement meaningless.
  5. Comparison. Values are compared as quantities, not as strings. 16 A and 16,0 A agree; 316 SS and A4 agree. Semantic equivalence in a review queue is the failure this system exists to prevent.
  6. The redline. A disagreement becomes a sentence addressed to a person, with the evidence boxed on the page and the counter-evidence panel filled in — including when it says nothing supports the catalog. That sentence is the finding.

Evidence is a character span, not a rectangle

The stored anchor is a character span in the canonical text layer. The rectangle you see on the page is derived from that span through a versioned projection, and regenerated when the extraction layer changes.

The alternative — storing coordinates — is simpler and breaks on the first parser upgrade, silently, in the direction of a box that used to be right. The projection is measured against rendered ink rather than assumed, because a box that lands two lines below the value discredits the product on screen faster than any wrong answer.

A decline is a result

Every record that is not audited carries exactly one named reason and appears in the interface. There are no silent skips anywhere in the pipeline, because a system that quietly skips what it cannot handle is indistinguishable from one that handled it.

The reasons include one most systems will not ship: calibration out of distribution — the system declaring it does not yet know how much to trust itself in this region. It costs coverage. Coverage is a number we publish.

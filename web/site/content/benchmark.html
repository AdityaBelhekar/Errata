Benchmark

Two of three kill-gates have been measured. Neither result is a win, and this page is not going to describe them as one.

Gate 2 — word-level grounding

Measured: 46.34% word-level grounding F1, against ExtractBench's best published 46.4%.

That is a dead heat, not a lead. Two further things have to be said plainly, because leaving them out is how this number would become a marketing claim:

  • The 46.34% belongs to a table-blind baseline — a deliberately limited extractor kept as a floor — not to the shipped extractor. Any sentence implying otherwise makes a claim this project's own README refuses to make.
  • The asymmetry the gate was designed to establish is not confirmed. A dead heat does not establish it, and no amount of restating the number will.

The metric is ExtractBench's own: a field counts as grounded-correct only when the value is accepted and the predicted box overlaps an accepted evidence box at IoU 0.5. Reusing a published metric rather than inventing one is deliberate — you do not want a measure of your own that nobody can check you against.

Gate 3 — not measured

Deferred. It needs SKU counts per ETIM class that three separate searches did not find. There is a proposal to derive the figure from the review queue's own adjudications; it is untested and it carries a real statistical problem — the queue is ranked, so its adjudications are not an i.i.d. sample, and treating them as one would produce a calibration curve that is confidently wrong.

A confidently wrong calibration curve is worse than no curve. So there is no curve, and the calibration surface that would display it is not built.

What would make these numbers stronger

  • A public corpus. Ours is not public. That exit criterion is half open and stays half open until it is.
  • Third-party reproduction. The numbers reproduce from a receipt on our machines. Nobody outside this project has re-derived them.

Both are recorded as open rather than quietly omitted, on the grounds that a benchmark page which lists only its strengths is an advertisement.

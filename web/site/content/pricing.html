Pricing

The honest version: the metering this page describes is specified and not built, so nothing below is a quote. What is real is the shape — what you would be charged for, and why.

What you would pay for

Not per SKU. A catalog of a million rows where 900,000 are already correct should not cost the same as one where 900,000 are wrong, and charging per row prices the work exactly backwards.

The unit is a verified attribute — a value checked against a document, with evidence stored and a reviewer's decision recorded where one was needed. Records the system declines are not billed, which is the only arrangement under which a decline stays honest: bill for declines and the incentive to decline less arrives the same day.

The four tiers

Work escalates only as far as it needs to. Most rows stop at T0.

T0 · Structural

The value is in a table, the table resolves into columns, and the row matches. No model involved. Cheapest by a wide margin and where the bulk of a clean catalog lands.

T1 · Text window

The value is in running text near an identifier. More work, more chances to be wrong, and the point at which the system starts abstaining rather than guessing between competing candidates.

T2 · Cross-document

More than one source, ranked by evidentiary weight. Where two sources of identical rank disagree, the system declines to arbitrate rather than picking one.

T3 · Human adjudication

A person decides. The most expensive tier, and the one the queue's ranking exists to ration — a reviewer's next thirty seconds should go where they are worth the most, which is not the same as where the model is least sure.

What is not built

  • The cost report that would show you the tier mix for your own catalog.
  • Metering, of any kind.
  • A per-tier cost measured on a real customer catalog. The tiers are specified; what each costs in practice depends on a mix nobody has measured outside our own corpus.

Until the cost report exists, any number quoted here would be a projection wearing the clothes of a measurement — which is the specific failure this product was built to catch in other people's data.
